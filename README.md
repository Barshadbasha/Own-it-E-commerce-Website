# Own-it-E-commerce-Website
OWN-IT is a backend ecommerce application developed using Java and Spring Boot. This project includes RESTful APIs for managing products, allowing users to perform operations like adding, retrieving, updating, and deleting product details. It follows the MVC architecture and uses Spring Data JPA to interact with a relational database. The backend handles HTTP requests using annotated controllers and supports clean JSON-based communication. Ideal for integration with a frontend or mobile app, this backend lays the foundation for a scalable ecommerce system. Testing can be done using Postman or Swagger UI.
